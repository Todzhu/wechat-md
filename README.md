# 微信公众号排版工作台 (WeChat-MD Studio)

一套采用 **Claude 风格左侧栏 + 双栏实时预览（Artifacts）架构** 的本地 Markdown 微信公众号与 CSDN 排版工作台。专为科研推文、文献深度解读、技术博客与 AI 专栏打造，支持 **100% 内联 CSS 富文本生成**、**LaTeX 数学公式转内联 SVG**、**代码块内联高亮与 Mac 装饰窗**、**本地图片自动映射/压缩内联/微信官方图床直传**。

---

## 核心特性

### 1. 微信公众号 100% 兼容排版引擎
- **全内联样式（Inline CSS）**：所有标题、段落、列表、引用块、表格与代码均在 DOM 树层面注入内联 `style`，一键粘贴到微信公众号后台不丢样式。
- **6 套科研与人文主题**：
  - **经典科研蓝**（`bioinfo-blue`）：默认风格，渐变左框二级标题
  - **人文陶土橙**（`claude-terracotta`）：Claude 衬线人文风格
  - **翡翠学术绿**（`nature-emerald`）：Cell / Nature 胶囊章节风格
  - **前沿极客紫**（`ai-violet`）：AI 与算法专栏风格
  - **CNS 学术红**（`cns-crimson`）：顶刊重磅速递风格
  - **极简墨韵黑**（`minimal-ink`）：深度长文阅读风格
- **细节自由微调**：支持任意自定义主色调、正文字号（`14px / 15px / 16px`）、段落行距（`1.75 / 1.85 / 2.0`）。

### 2. 科研推文专属增强
- **LaTeX 公式无损转 SVG**：基于 MathJax 3 将行内公式 `$...$` 与块级公式 `$$...$$` 渲染为自包含内联 `<svg>`，粘贴到公众号无需外挂字体；自动保护代码块与行内代码中的 `$`（如 R 语言 `df$col`、Shell `$PATH`），杜绝误解析。
- **代码高亮内联化 + Mac 窗口顶栏**：基于 Highlight.js 并将语法着色直接转为内联 `style="color: ..."`，粘贴到微信编辑器后依然保持完整代码配色；可选 Mac 红黄绿圆点装饰窗。
- **自动图注（Figure Legend）**：自动提取 Markdown 图片 `![图注内容](路径)` 中的 `alt` 文本，在图片下方生成居中的 `▲ 图注` 说明。
- **外链自动转文末参考文献角标**：自动将正文中的非微信外部链接（如 DOI、GitHub、Zenodo）转为上标 `[1]`，并在文末自动汇总生成「文中参考链接与开源资源」卡片。

### 3. 本地图片无缝流转与多平台一键发布
- **本地路径实时映射**：Markdown 中引用的相对路径（如 `./figures/Fig1.png`）或本地绝对路径（如 `E:/.../Fig1.png`）均由本地服务实时代理渲染。
- **剪贴板截图粘贴 & 拖拽上传**：支持在编辑器中直接 `Ctrl+V` 粘贴截图，或将图片 / `.md` 文件直接拖入窗口。
- **三种图片发布模式**：
  1. **免配置自动内联（默认）**：一键复制时由后端 Pillow 自动将本地图片自适应缩放（最大宽度 `1080px`）、压缩转为高清 JPEG Base64 嵌入剪贴板。
  2. **微信官方图床直传（可选）**：填写公众号 `AppID` 与 `AppSecret` 后，一键将正文本地图片上传至微信官方 `media/uploadimg` 接口并替换为 `mmbiz.qpic.cn` 永久链接（不占用公众号 5000 张永久素材上限）。
  3. **独立 HTML 离线导出**：一键导出内联全部样式与图片的单个 `.html` 文件，离线亦可完整浏览。
- **双平台一键复制**：底部固定支持 **微信公众号**（内联富文本）与 **CSDN 博客**（同时写入富文本 HTML 与原始 Markdown，通配 CSDN 两种编辑器）。

### 4. 现代化编辑器体验
- **可拖拽分栏手柄**：编辑区与预览区之间支持鼠标左右拖动调节宽度比例（`22% ~ 78%`），双击分隔条一键恢复 `50% : 50%` 等宽。
- **仿真预览与交互**：支持 **宽屏 / 手机** 视图切换、**浅色 / 深色** 模式预览；预览区顶部的标题、原创标识、公众号名称与发布地区均可直接点击编辑并自动记忆。
- **防丢稿机制**：编辑内容实时防抖缓存至本地草稿箱（`localStorage`），未保存关闭页面时自动提醒，且保存本地文档时具备外部修改冲突检测（`409 Conflict`）。

## 项目结构

```text
wechat-md/
├── server.py               # Python 多线程后端服务（静态资源、文件读写、图片压缩与微信 API）
├── 启动排版工作台.bat       # Windows 一键启动脚本
├── requirements.txt        # Python 依赖（Pillow）
├── static/
│   ├── index.html          # 工作台主界面（Claude 风格左栏 + 右侧双栏）
│   ├── style.css           # 界面样式表与响应式布局
│   └── app.js              # Markdown/MathJax/Highlight 内联渲染引擎与交互逻辑
└── uploads/                # 粘贴或上传图片的本地去重存储目录
```

## 快速开始

### 1. 环境准备
- **Python 3.8+**
- 安装图片自适应压缩依赖 `Pillow`（推荐）：
  ```bash
  pip install -r requirements.txt
  ```

### 2. 启动服务

- **Windows 一键启动**：双击运行 [`启动排版工作台.bat`](./启动排版工作台.bat)，浏览器将自动打开工作台。
- **命令行启动**：
  ```bash
  python server.py 8765 --open
  ```
  启动后访问：`http://127.0.0.1:8765`

## 环境变量配置（可选）

| 环境变量 | 说明 | 默认值 |
| :--- | :--- | :--- |
| `WECHAT_MD_WORKSPACE` | 默认扫描与保存 `.md` 文档的工作区目录 | 项目下 `./workspace` |
| `WECHAT_MD_ROOT` | 允许读写 `.md` 文档的根目录范围 | 与工作区目录相同或上级目录 |

## 常用快捷键与操作技巧

| 操作 | 快捷键 / 方式 |
| :--- | :--- |
| 保存当前文档到本地工作区 | `Ctrl + S`（macOS 为 `Cmd + S`） |
| 选中文字加粗 | `Ctrl + B` |
| 选中文字斜体 | `Ctrl + I` |
| 代码 / 列表缩进与反缩进 | `Tab` / `Shift + Tab` |
| 插入截图 | 在编辑器中直接 `Ctrl + V` 粘贴剪贴板图片 |
| 导入外部文档或图片 | 直接将 `.md` 文件或图片文件拖入主工作区窗口 |
| 调节左右面板宽度 | 按住中间分隔条左右拖动；**双击分隔条**恢复 `50% : 50%` 等宽 |
